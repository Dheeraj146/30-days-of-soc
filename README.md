# 30 Days of SOC

A hands-on 30-day journey to build practical Security Operations Center (SOC) analyst skills through labs, investigations, detection engineering, and incident response.

## 🎯 Objective

Build practical experience across:

- SOC operations and alert triage
- SIEM and security monitoring
- Wazuh
- Windows and Linux security
- Active Directory
- Network security and traffic analysis
- Threat intelligence
- Detection engineering
- Incident response
- Digital forensics
- Cloud security

## 🧰 Core Tools

- Wazuh
- Windows Server / Windows 10 / Windows 11
- Linux
- Kali Linux
- Active Directory
- Sysmon
- Wireshark
- PowerShell
- Sigma
- Azure
